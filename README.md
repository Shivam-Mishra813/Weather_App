# 🌦️ SkyCast – Weather App

SkyCast is a simple and responsive weather application that helps users check the current weather and forecast for different cities. I built this project using HTML, CSS, and JavaScript to practice frontend development and working with real-time weather APIs.

## ✨ Features

- Search for weather by city name.
- View current temperature and weather conditions.
- Check humidity, wind speed, pressure, and visibility.
- View hourly and 5-day weather forecasts.
- Switch between Celsius and Fahrenheit.
- Get weather information using your current location.
- Switch between light and dark mode.
- Responsive design for mobile, tablet, and desktop.
- Handle invalid city names and API errors.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Fetch API
- VS Code and Live Server

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Shivam-Mishra813/Weather_App
   ```

2. Open the project folder in VS Code.

3. Get an API key from [OpenWeather](https://openweathermap.org/api).

4. Add your API key in the configuration section of `script.js`, following the instructions in the code.

5. Install the Live Server extension in VS Code.

6. Right-click `index.html` and select **Open with Live Server**.

7. Search for a city and explore its weather information.

## 🔑 API Configuration

This project uses the OpenWeather API to fetch weather information.

You need your own API key to access live weather data. Keep in mind that API keys used in frontend JavaScript are visible to visitors. For a public production deployment, use a backend or serverless function to protect your key.
